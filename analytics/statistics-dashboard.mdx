Open **Analytics** in your [dashboard](https://dashboard.serversmtp.com). Use **Overview** to review email records and **Charts** to examine aggregate activity.

Review sent, delivered, opened, clicked, bounced, and spam-report activity for the selected period. Open and click measurements depend on [tracking settings](/analytics/email-tracking) and the recipient's email client.

## Email records

Filter by date and status to investigate a message or a delivery pattern. Review the message's recipient, sender, subject, date, status, and available failure reason.

A delivered message was accepted by the recipient's mail server. Its final placement in an inbox or spam folder is determined by that server.

## Status definitions

| Status | Description |
|---|---|
| **NEW** | Queued and waiting to be sent. |
| **DEFER** | Temporarily deferred; delivery is retried. |
| **SUCCESS** | Accepted by the recipient's mail server. |
| **OPEN** | The open-tracking image loaded. |
| **CLICK** | A tracked link was requested. |
| **REPORT** | A spam complaint was recorded. |
| **FAIL** | A permanent delivery failure; the message will not be retried. |
| **SYSFAIL** | A system-level failure prevented delivery. |
| **UNSUB** | An unsubscribe was recorded. |

See [suppression management](/deliverability/bounce-spam-management) for addresses excluded from future sends.

## Date range and retention

Select a period within the history available to your plan:

| Plan | Analytics availability |
|---|---|
| Free | 30-day demo |
| Basic | 30-day history |
| Pro | 365-day history |
| Enterprise | 365-day history |

Export records you need to retain before they leave your available history. Check [current pricing](https://serversmtp.com/pricing/) for plan details.

## Export data

Click **Export** in **Analytics** to download CSV data for your selected view.

For API exports, use `GET /analytics/csv` with `from` and `to` dates in `YYYY-MM-DD` format. Authenticate with a key that has **Statistics & Management APIs** enabled:

```bash Terminal
curl --get 'https://pro.api.serversmtp.com/api/v2/analytics/csv' \
  -H "consumerKey: $TURBOSMTP_CONSUMER_KEY" \
  -H "consumerSecret: $TURBOSMTP_CONSUMER_SECRET" \
  --data-urlencode 'from=2026-10-01' \
  --data-urlencode 'to=2026-10-27' \
  --output analytics.csv
```

Set the environment variables locally and choose your date range. The CSV contains message ID, status, subject, sender, recipient, date, reason, and Consumer Key. See the [analytics API reference](/api-reference/analytics) for additional filters and individual-message lookups.

## Activity reports

Open **Settings → Notifications → Activity reports** to configure **daily**, **weekly**, or **monthly** email summaries of account activity.
