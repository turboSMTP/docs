**Status: Available.** The [official turboSMTP plugin](https://wordpress.org/plugins/turbosmtp/) routes messages sent through WordPress's `wp_mail()` function to turboSMTP. This includes WooCommerce and form plugins that use `wp_mail()`. A plugin with its own delivery service may need separate configuration.

<Note>
  Use one mail delivery plugin at a time. Configure [SPF and DKIM](/deliverability/spf-dkim-dmarc) for your sending domain. Authentication helps receivers verify your mail; inbox placement still depends on their filtering decisions.
</Note>

## Configure the plugin

<Steps>
  <Step title="Install the TurboSMTP plugin">
    In your WordPress admin, go to **Plugins → Add New Plugin**. Install and activate **turboSMTP**. Follow its credential setup with your [Consumer Key and Consumer Secret](/get-started/api-keys). In API mode the plugin always uses the Global endpoint `api.turbo-smtp.com`, and the key needs **HTTP API Sending** permission. To send through European servers, use the plugin's SMTP mode instead.
  </Step>
  <Step title="Or choose SMTP sending">
    The plugin's SMTP mode lets you pick the Global or European host. The username field is labelled **Username (email)**; enter your Consumer Key there, not your account email. The same values work in other SMTP plugins such as WP Mail SMTP (**Other SMTP**):

    | Setting | Value |
    | --- | --- |
    | SMTP Host | `pro.turbo-smtp.com` (or `pro.eu.turbo-smtp.com` for European servers) |
    | Port | `587` (TLS) |
    | Encryption | `TLS` / `STARTTLS` |
    | Authentication | `Yes` |
    | Username | Your **Consumer Key** from **Settings → Integrations → API Keys → Edit** |
    | Password | Your **Consumer Secret** |

    Both hosts support STARTTLS on 587 or 2525 and implicit TLS on 465 or 25025. Port 25 is also available. Enable **SMTP Sending** on the key and check any IP restrictions.
  </Step>
  <Step title="Send a test email">
    Use the plugin's test email feature and check **Analytics** in turboSMTP. Then test an actual form submission or order email to confirm that application's delivery path.
  </Step>
</Steps>

## Validate form submissions

For supported form integrations and validation credit requirements, see the [Email Validation guide](/account/email-validation). Validation can identify address problems before sending; it cannot guarantee that an address is safe or that a message will reach the inbox.
