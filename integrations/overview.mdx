## Integration status

Check each integration's status and version requirements before installing it.

| Status | Meaning |
| --- | --- |
| **Available** | Published by the project. Check supported versions and test your configuration. |
| **Merged upstream** | Accepted by the project; a stable release may still be pending. |
| **In development** | No stable release is documented. Use the suggested alternative. |

## Connect any other tool

Any app that lets you set a custom SMTP server works with turboSMTP. Use `pro.turbo-smtp.com` (or `pro.eu.turbo-smtp.com` for European servers), authenticate with your [Consumer Key and Consumer Secret](/get-started/api-keys), and see [SMTP Setup](/get-started/smtp-configuration) for ports. For custom code, call the [Email API](/sending/email-api) directly.
