If a tool supports SMTP but is not listed, you can still connect it with the [standard SMTP settings](/get-started/smtp-configuration).

## Integration status

Every integration page shows its release status at the top, so you know whether you can use it in production today.

| Status | Meaning |
| --- | --- |
| **Available** | Released in an official version of the framework or tool. Ready for production. |
| **Merged upstream** | Accepted by the project and shipping in its next release. Check package availability before installing. |
| **In development** | Implemented but not yet published. Use the suggested alternative until it is released. |

## Connect any other tool

Any app that lets you set a custom SMTP server works with turboSMTP. Use `pro.turbo-smtp.com` (or `pro.eu.turbo-smtp.com` for European servers), authenticate with your [Consumer Key and Consumer Secret](/get-started/api-keys), and see [SMTP Setup](/get-started/smtp-configuration) for ports. For custom code, call the [Email API](/sending/email-api) directly.
