**Status: Available in Uptime Kuma 2.5.3.** Its turboSMTP provider sends monitor notifications through the HTTP API and supports Global or EU endpoints plus To, Cc, and Bcc recipients. Install or update Uptime Kuma using the project's [installation instructions](https://github.com/louislam/uptime-kuma#-how-to-install).

## Configure notifications

<Steps>
  <Step title="Open notification settings">
    In Uptime Kuma, go to **Settings → Notifications**.
  </Step>
  <Step title="Create a turboSMTP notification">
    Create a new notification and select **TurboSMTP** as the notification type.
  </Step>
  <Step title="Enter your credentials">
    Enter your [Consumer Key and Consumer Secret](/get-started/api-keys). Enable **HTTP API Sending** and check any IP restrictions on the key.
  </Step>
  <Step title="Choose infrastructure">
    Select **US (Default)** for `https://api.turbo-smtp.com/api/v2` or **EU** for `https://api.eu.turbo-smtp.com/api/v2`.
  </Step>
  <Step title="Set sender and recipients">
    Enter a verified From address and the To, Cc, or Bcc recipients.
  </Step>
  <Step title="Test and assign">
    Use the built-in test, then assign the notification to your monitors.
  </Step>
</Steps>
