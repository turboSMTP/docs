## Prefer a framework integration?

If your framework already has a mail abstraction, use the native integration instead of an SDK:

- **Symfony**: [Symfony Mailer bridge status and SMTP alternative](/integrations/symfony-mailer)
- **Node.js**: [Nodemailer service presets](/integrations/nodemailer)
- **Elixir and Phoenix**: [Swoosh adapter](/integrations/swoosh)

For any other language, see the [code examples](/sending/code-examples) for cURL, Python, Node.js, PHP, Ruby, Go, Java, and C#.
