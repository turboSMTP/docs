**Status: Available through SMTP.** Configure an outgoing SMTP server in a client that supports custom SMTP settings. Menu names vary by client version. For more clients, see [SMTP Setup](/get-started/smtp-configuration).

Use `pro.turbo-smtp.com` for Global or `pro.eu.turbo-smtp.com` for EU sending in either configuration below. Your SMTP username is your Consumer Key and your password is your Consumer Secret.

<Tabs>
  <Tab title="Microsoft Outlook">
    Open Outlook and navigate to **File → Account Settings → Account Settings → New** (or edit an existing account). Enter the following SMTP settings in the outgoing mail server section:

    | Setting | Value |
    | --- | --- |
    | SMTP Server | `pro.turbo-smtp.com` |
    | Port | `587` |
    | Encryption | `STARTTLS` |
    | Authentication required | `Yes` |
    | Username | Your **Consumer Key** |
    | Password | Your **Consumer Secret** |

    Save the settings and send a test message to confirm the connection.
  </Tab>
  <Tab title="Mozilla Thunderbird">
    In Thunderbird, go to **Account Settings → Outgoing Server (SMTP) → Add**. Enter the following details:

    | Setting | Value |
    | --- | --- |
    | Server Name | `pro.turbo-smtp.com` |
    | Port | `587` |
    | Connection Security | `STARTTLS` |
    | Authentication Method | `Normal password` |
    | Username | Your **Consumer Key** |

    Save the outgoing server, then assign it to your account under **Account Settings → [Your Account] → Outgoing Server**. Thunderbird will prompt for your Consumer Secret on the first send.
  </Tab>
</Tabs>

<Tip>
  Both hosts support **587** and **2525** with STARTTLS, **465** and **25025** with implicit TLS, and port **25**. Match your client's encryption setting to the port.
</Tip>
