Nodemailer, the most widely used email library for Node.js, includes turboSMTP in its list of [well-known services](https://nodemailer.com/smtp/well-known-services). Set `service` to `TurboSMTP` or `TurboSMTP-EU` and Nodemailer fills in the host, port, and TLS settings for you.

| Service ID | SMTP host | Port | Secure |
| --- | --- | --- | --- |
| `TurboSMTP` | `pro.turbo-smtp.com` | 465 | yes |
| `TurboSMTP-EU` | `pro.eu.turbo-smtp.com` | 465 | yes |

## Install Nodemailer

<CodeGroup>

```bash npm
npm install nodemailer
```

```bash yarn
yarn add nodemailer
```

```bash pnpm
pnpm add nodemailer
```

</CodeGroup>

## Send the first message

Authenticate with your turboSMTP account email as the username and your [Consumer Secret](/get-started/api-keys) as the password, as on any [SMTP connection](/get-started/smtp-configuration).

```javascript send.js
import nodemailer from "nodemailer";

const transporter = nodemailer.createTransport({
  service: "TurboSMTP", // or "TurboSMTP-EU" for European servers
  auth: {
    user: process.env.TURBOSMTP_USER,
    pass: process.env.TURBOSMTP_SECRET,
  },
});

await transporter.sendMail({
  from: "noreply@your-domain.example",
  to: "developer@example.com",
  subject: "Hello from Node.js",
  text: "The turboSMTP relay is working.",
});
```

<Tip>
  Use `TurboSMTP-EU` to send through turboSMTP's European servers and keep your email data inside the EU. See [GDPR and data residency](/api-reference/base-urls#gdpr-and-data-residency).
</Tip>

## HTTP API transport

<Info>
  A dedicated Nodemailer transport for the turboSMTP HTTP API is in development and not yet published to npm. Until then, use the SMTP service presets above, or call the [Email API](/sending/email-api) directly.
</Info>
