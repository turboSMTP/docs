**Status: Available in Nodemailer 9.0.4 and later.** Nodemailer includes turboSMTP in its list of [well-known services](https://nodemailer.com/smtp/well-known-services). Set `service` to `TurboSMTP` or `TurboSMTP-EU` and Nodemailer fills in the host, port, and TLS settings for you.

| Service ID | SMTP host | Port | Secure |
| --- | --- | --- | --- |
| `TurboSMTP` | `pro.turbo-smtp.com` | 465 | yes |
| `TurboSMTP-EU` | `pro.eu.turbo-smtp.com` | 465 | yes |

## Install Nodemailer

<CodeGroup>

```bash npm
npm install nodemailer
```

```bash yarn
yarn add nodemailer
```

```bash pnpm
pnpm add nodemailer
```

</CodeGroup>

## Send the first message

Authenticate with your [Consumer Key](/get-started/api-keys) as the username and your Consumer Secret as the password, as on any [SMTP connection](/get-started/smtp-configuration).

Enable **SMTP Sending** on the key and check any IP restrictions before sending.

```javascript send.js
import nodemailer from "nodemailer";

const transporter = nodemailer.createTransport({
  service: "TurboSMTP", // or "TurboSMTP-EU" for European servers
  auth: {
    user: process.env.TURBOSMTP_CONSUMER_KEY,
    pass: process.env.TURBOSMTP_CONSUMER_SECRET,
  },
});

await transporter.sendMail({
  from: "noreply@your-domain.example",
  to: "developer@example.com",
  subject: "Hello from Node.js",
  text: "The turboSMTP relay is working.",
});
```

<Tip>
  The presets use implicit TLS on port 465. For manual configuration, both hosts also support implicit TLS on 25025 and STARTTLS on 587 or 2525; port 25 is available. See [SMTP Setup](/get-started/smtp-configuration).
</Tip>
