**Status: Available from Swoosh 1.28.0.** `Swoosh.Adapters.TurboSMTP` sends email and attachments through the turboSMTP HTTP API. It supports Global and EU endpoints, provider options, and automatic inline-CID qualification. See the [published package](https://hex.pm/packages/swoosh/1.28.0).

## Install

Add `{:swoosh, "~> 1.28"}` to your Mix dependencies and run `mix deps.get`. Configure an [API client supported by Swoosh](https://hexdocs.pm/swoosh/Swoosh.html#module-installation), such as Req, Finch, or Hackney.

## Configure the mailer

Add the adapter to your mailer config and load your [Consumer Key and Consumer Secret](/get-started/api-keys) from environment variables.

<CodeGroup>

```elixir Global
config :sample, Sample.Mailer,
  adapter: Swoosh.Adapters.TurboSMTP,
  consumer_key: System.fetch_env!("TURBOSMTP_CONSUMER_KEY"),
  consumer_secret: System.fetch_env!("TURBOSMTP_CONSUMER_SECRET")
```

```elixir EU
config :sample, Sample.Mailer,
  adapter: Swoosh.Adapters.TurboSMTP,
  consumer_key: System.fetch_env!("TURBOSMTP_CONSUMER_KEY"),
  consumer_secret: System.fetch_env!("TURBOSMTP_CONSUMER_SECRET"),
  base_url: "https://api.eu.turbo-smtp.com/api/v2"
```

</CodeGroup>

Place the chosen configuration in `config/runtime.exs`.

The default Global base URL is `https://api.turbo-smtp.com/api/v2`. Define your mailer if you do not already have one:

```elixir lib/sample/mailer.ex
defmodule Sample.Mailer do
  use Swoosh.Mailer, otp_app: :sample
end
```

<Tip>
  Set `base_url` to `https://api.eu.turbo-smtp.com/api/v2` to send through turboSMTP's European servers. See [GDPR and data residency](/api-reference/base-urls#gdpr-and-data-residency).
</Tip>

## Send the first message

```elixir
import Swoosh.Email

new()
|> from("noreply@your-domain.example")
|> to("developer@example.com")
|> subject("Hello from Elixir")
|> text_body("The TurboSMTP adapter is working.")
|> Sample.Mailer.deliver()
```
