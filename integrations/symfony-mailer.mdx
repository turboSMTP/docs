**Status: Merged upstream for the upcoming Symfony 8.2 release.** The bridge source supports the HTTP API, SMTP relay, EU endpoints, and delivery webhooks through Symfony's RemoteEvent component.

<Note>
  Checked on 27 October 2026: [Symfony 8.2 is under development](https://symfony.com/releases/8.2), with release planned for November 2026. [Packagist currently lists a development version](https://packagist.org/packages/symfony/turbo-smtp-mailer). The bridge configuration below is for that upcoming release.
</Note>

## Use standard SMTP today

Existing Symfony Mailer versions can use turboSMTP through their built-in SMTP transport:

```bash .env
# Global, STARTTLS on port 587
MAILER_DSN=smtp://KEY:SECRET@pro.turbo-smtp.com:587

# EU, STARTTLS on port 587
MAILER_DSN=smtp://KEY:SECRET@pro.eu.turbo-smtp.com:587
```

Use your Consumer Key as `KEY` and Consumer Secret as `SECRET`. URL-encode credentials that contain reserved URI characters. Both hosts support STARTTLS on 587 or 2525 and implicit TLS on 465 or 25025; port 25 is also available.

## Install the bridge after its stable release

Once a stable version is published and compatible with your application:

```bash
composer require symfony/turbo-smtp-mailer
```

## Choose a transport

Set `MAILER_DSN` in your `.env` file. Replace `KEY` and `SECRET` with your [Consumer Key and Consumer Secret](/get-started/api-keys).

```bash .env
# HTTP API, Global
MAILER_DSN=turbosmtp+api://KEY:SECRET@default

# HTTP API, EU
MAILER_DSN=turbosmtp+api://KEY:SECRET@api.eu.turbo-smtp.com

# SMTP relay, Global
MAILER_DSN=turbosmtp+smtp://KEY:SECRET@default

# SMTP relay, EU
MAILER_DSN=turbosmtp+smtp://KEY:SECRET@pro.eu.turbo-smtp.com
```

<Tip>
  The bridge's SMTP transport defaults to port 587 with STARTTLS on both hosts. Use the EU DSNs for the European sending endpoint. See [base URLs](/api-reference/base-urls).
</Tip>

## Send the first message

```php
use Symfony\Component\Mailer\MailerInterface;
use Symfony\Component\Mime\Email;

$email = (new Email())
    ->from('noreply@your-domain.example')
    ->to('developer@example.com')
    ->subject('Hello from Symfony')
    ->text('The TurboSMTP bridge is working.');

$mailer->send($email);
```

## Delivery events

The upcoming bridge includes a `turbosmtp` webhook parser and RemoteEvent converter. Configure the callback under **Settings → Notifications → Webhooks → Edit**, subject to your plan and event availability. Requests are unsigned; configure HTTP Basic credentials in the callback URL and the matching route secret. See [webhooks](/analytics/webhooks).
