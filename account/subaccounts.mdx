Sub-accounts separate sending credentials and activity for teams or customers under a parent account. Check your plan's allowance before creating one. Current [pricing](https://serversmtp.com/pricing/) lists one sub-account on Free and Basic and up to 100 on Pro. Confirm your Enterprise allowance with sales or in your agreement.

## Create a sub-account

Sign in to your [dashboard](https://dashboard.serversmtp.com), open **Sub Accounts**, and start creating a sub-account. The wizard has four steps:

<Steps>
  <Step title="Enter account details">
    Enter the email address and profile details. Set and confirm a password with at least 10 characters, an uppercase letter, a lowercase letter, and a digit.
  </Step>
  <Step title="Choose an IP">
    Select an IP already assigned to the parent account.
  </Step>
  <Step title="Review domain verification">
    Follow the domain verification instructions shown in the wizard.
  </Step>
  <Step title="Confirm and create">
    Review the details, accept the required policy, and click **Create**.
  </Step>
</Steps>

After creation, set the sending limit from the sub-account list. The parent sets the initial password during creation and provides the login details to the account holder securely.

## Sending credentials

New sub-accounts do not receive an API key automatically. In the sub-account dashboard, open **Settings → Integrations → API Keys → Edit** and create a key with the required services enabled.

For SMTP, use the **Consumer Key** as the username and **Consumer Secret** as the password. The dashboard login email is not the SMTP username for a newly created key. See [API keys](/get-started/api-keys).

## Limits and account status

Use the sub-account list to review usage, change sending limits, and activate or deactivate accounts. Sending limits and account status are separate settings from profile details.

## Manage sub-accounts through the API

Send `consumerKey` and `consumerSecret` headers using a parent key with **Statistics & Management APIs** enabled.

Paths below are relative to `https://pro.api.serversmtp.com/api/v2`.

| Method | Endpoint | Purpose |
|---|---|---|
| `GET` | `/subaccounts/list` | List sub-accounts and usage |
| `POST` | `/subaccounts` | Create an account with profile, password, IP, and policy acceptance |
| `GET` | `/subaccounts/{Id}` | Retrieve an account |
| `PATCH` | `/subaccounts/{Id}` | Update profile details with policy acceptance |
| `POST` | `/subaccounts/{Id}/updatesubaccountsmtplimit` | Change the sending limit |
| `POST` | `/subaccounts/{Id}/updatesubaccountstatus` | Change active status |
| `DELETE` | `/subaccounts/{Id}` | Soft-delete an account |

See the [sub-accounts API reference](/api-reference/subaccounts) for request fields, responses, and the separate authorization and branding operations.

## Reseller branding

Approved resellers can configure a logo and agency details for sub-accounts. Confirm your reseller arrangement and branding options with turboSMTP before offering the service to customers. See the [terms and conditions](https://serversmtp.com/terms-and-conditions/).
