Email validation helps identify invalid or risky addresses before you send. It does not guarantee delivery or replace permission to email a recipient.

## Review validation categories

| Category | Meaning | Suggested action |
|---|---|---|
| **Valid** | The address passed validation. | Keep if you have permission to send. |
| **Invalid** | The address has a permanent error or does not exist. | Remove it. |
| **Catch-All** | The domain accepts mail for addresses that may not exist. | Review the risk before sending. |
| **Spamtrap** | The address is identified as a spam trap. | Exclude it. |
| **Abuse** | The address is associated with spam complaints. | Exclude it. |
| **Do Not Mail** | The address is flagged, for example as role-based or disposable. | Review or exclude it. |
| **Unknown** | Validation could not reach a conclusion. | Revalidate or exclude it from the send. |

## Choose a validation method

<Tabs>
  <Tab title="Dashboard">
    1. Open **Addons → Go to email validator** in the [dashboard](https://dashboard.serversmtp.com).
    2. Click **Import File** and upload a CSV or TXT file, or enter contacts manually.
    3. Start validation for the imported list and check its progress.
    4. Review the categorized results and download the addresses you want to retain.

    Validation uses its own credits. Check the balance before starting a large list.
  </Tab>
  <Tab title="WordPress">
    The turboSMTP Email Validator plugin checks addresses submitted through supported WordPress forms. Connect the credentials requested by the plugin, choose which results to accept, and configure any trusted-address or domain whitelist.

    Supported integrations include Contact Form 7, WPForms, WooCommerce, Gravity Forms, Elementor Forms, MC4WP Mailchimp Forms, and native registration and comment forms. See the [official validation guide](https://serversmtp.com/email-validation-tool/) for plugin links and setup details.
  </Tab>
  <Tab title="API">
    Use the validation API for individual addresses or batch lists. Send `consumerKey` and `consumerSecret` headers with a key that has **Statistics & Management APIs** enabled.

    Paths are relative to `https://pro.api.serversmtp.com/api/v2`.

    | Method | Endpoint | Purpose |
    |---|---|---|
    | `POST` | `/emailvalidation/validateEmail` | Validate one address |
    | `POST` | `/emailvalidation/upload` | Import a list |
    | `POST` | `/emailvalidation/lists/{Id}/validate` | Start validation of an imported list |
    | `GET` | `/emailvalidation/lists` | List validation jobs |
    | `GET` | `/emailvalidation/lists/{Id}` | Check processing progress |
    | `GET` | `/emailvalidation/lists/{Id}/emails` | Read categorized addresses |
    | `GET` | `/emailvalidation/lists/{Id}/csv` | Download results |

    <Note>
      Uploading a list does not start validation. Call the list's `validate` endpoint, wait for processing to finish, then retrieve the results.
    </Note>

    See the [email validation API reference](/api-reference/email-validation) for request formats, result fields, and credit purchases.
  </Tab>
</Tabs>
