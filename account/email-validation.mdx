Before you send a campaign, every address on your list represents either a real person or a liability. Invalid addresses cause bounces, spam traps silently destroy your sender reputation, and catch-all domains inflate your open rates with phantom deliveries. turboSMTP's Email Validation Tool lets you screen every address in your list — identifying safe contacts, flagging risky ones, and removing the dangerous ones — so every send goes to a real, active inbox.

## Validation categories

When you validate a list, turboSMTP categorizes every address into one of seven groups:

| Category | Description | Recommended action |
|----------|-------------|-------------------|
| **Valid** | Safe addresses with less than 2% bounce risk. | Send freely. |
| **Invalid** | Non-existent addresses or permanent errors. | Remove from your list immediately. |
| **Catch-All** | The domain accepts all incoming mail, including addresses that don't exist. | Treat as risky; suppress from important sends. |
| **Spamtrap** | Addresses set up specifically to catch spammers. Sending to these can cause blacklisting. | Remove immediately — extremely dangerous. |
| **Abuse** | Addresses associated with known spam reporters. | Remove to prevent complaint spikes. |
| **Do Not Mail** | Role-based addresses (e.g., `info@`, `admin@`) and disposable email providers. | Remove to avoid low engagement and policy violations. |
| **Unknown** | Could not be validated — the address's mail server was unreachable or returned no conclusive response. | Suppress from high-volume sends; revalidate later. |

## Three ways to validate

<Tabs>
  <Tab title="Dashboard">
    The dashboard validator is the fastest way to clean an existing list in bulk. Upload your file and get categorized results in minutes — no code required.

    <Steps>
      <Step title="Go to Addons → Email Validator">
        Log in to your [turboSMTP dashboard](https://dashboard.serversmtp.com), click **Addons** in the left navigation, then select **Go to Email Validator**.
      </Step>
      <Step title="Click Import File">
        Click the **Import File** button to open the import dialog.
      </Step>
      <Step title="Upload your list">
        Choose **Import from a file** and upload a CSV or TXT file containing your email addresses. Alternatively, add individual contacts manually using the text input.
      </Step>
      <Step title="Wait for processing">
        turboSMTP processes your list and categorizes every address. Processing time depends on list size — a list of thousands of addresses typically completes within a few minutes.
      </Step>
      <Step title="Download your clean list">
        Once processing is complete, review the results grouped by category. Download the filtered list of **Valid** addresses, ready to use in your next campaign.
      </Step>
    </Steps>
  </Tab>
  <Tab title="WordPress Plugin">
    The turboSMTP Email Validator plugin validates email addresses in real time the moment a visitor submits a form on your WordPress site. This prevents invalid, fake, or disposable addresses from ever entering your database — eliminating the need to clean lists after the fact.

    The plugin works natively with:

    - **Contact Form 7**
    - **WPForms**
    - **WooCommerce**
    - **Gravity Forms**
    - **Elementor Forms**
    - **MC4WP Mailchimp Forms**
    - WordPress native registration and comment forms

    **To install:**

    1. In your WordPress admin, go to **Plugins → Add New Plugin**.
    2. Search for **TurboSMTP Email Validator** and click **Install Now**, then **Activate**.
    3. In the plugin settings, enter your turboSMTP API key and configure which validation statuses to accept or reject.
    4. Optionally, add trusted emails or domains to a whitelist to avoid spending validation credits on known-good addresses.

    No coding is required. Once activated, the plugin automatically intercepts form submissions and blocks addresses that fail your configured validation rules.
  </Tab>
  <Tab title="API">
    The Email Validation API lets you integrate validation directly into any application, CRM, SaaS platform, or automated data pipeline. Use it to validate addresses at the point of collection (e.g., during user registration) or to run batch validation jobs programmatically.

    The Email Validation API exposes four endpoints covering the full validation workflow:

    | Method | Endpoint | Description |
    |--------|----------|-------------|
    | `POST` | `/api/v2/emailvalidation/validateEmail` | Validate a single address |
    | `POST` | `/api/v2/emailvalidation/upload` | Upload a list for bulk validation |
    | `GET` | `/api/v2/emailvalidation/lists` | Retrieve all validation lists for your account |
    | `GET` | `/api/v2/emailvalidation/lists/{Id}/csv` | Download results for a validation list as CSV |

    **Validate a single address:**

    ```bash Terminal
    POST https://pro.api.serversmtp.com/api/v2/emailvalidation/validateEmail
    ```

    **Upload a list for bulk validation:**

    ```bash Terminal
    POST https://pro.api.serversmtp.com/api/v2/emailvalidation/upload
    ```

    **List all validation jobs:**

    ```bash Terminal
    GET https://pro.api.serversmtp.com/api/v2/emailvalidation/lists
    ```

    **Download results as CSV:**

    ```bash Terminal
    GET https://pro.api.serversmtp.com/api/v2/emailvalidation/lists/{Id}/csv
    ```

    All endpoints return the same validation categories as the dashboard tool (Valid, Invalid, Catch-All, Spamtrap, Abuse, Do Not Mail, Unknown), giving you full flexibility to define your own acceptance logic within your application.

    Include your API key in the `Authorization` header for all requests (raw key — no `Bearer` prefix). See the [API reference](/api-reference/email-validation) for full request and response documentation.
  </Tab>
</Tabs>

<Tip>
  Validate your contact list every **8–12 months**. Email addresses decay over time as people change jobs, abandon accounts, or switch providers. Regular validation keeps your bounce rate below 2%, protects your sender reputation, and ensures you're not wasting email credits on addresses that can never receive your messages.
</Tip>
