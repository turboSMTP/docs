### 33\. What is Smart Routing?

Smart Routing is a feature that automatically rotates between multiple shared IPs when sending emails. 
If one IP encounters a delay, deferral, or temporary block, the system will retry the delivery using a different IP.

This intelligent routing significantly improves deliverability and eliminates the need to manually request an IP change — everything happens automatically in the background. 
It’s a powerful way to reduce delivery issues and ensure more reliable inbox placement, especially for senders on shared IPs.
