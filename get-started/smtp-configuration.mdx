Use turboSMTP as the outgoing SMTP server in your mail client, CMS, or application. Choose the global or EU host, create a key with **SMTP Sending** enabled, and configure a port with its matching encryption mode.

## SMTP server settings

Use the following settings when configuring any client or application to send through turboSMTP:

| Setting | Value |
|---|---|
| **SMTP Host** | `pro.turbo-smtp.com` |
| **SMTP Host (EU)** | `pro.eu.turbo-smtp.com`: EU sending route |
| **Port (recommended)** | `587` : TLS / STARTTLS |
| **Ports (implicit TLS)** | `465`, `25025` |
| **Other STARTTLS ports** | `2525`, `25` |
| **Authentication** | Required : PLAIN or LOGIN |
| **Username** | Your **Consumer Key** (from Settings → Integrations → API Keys) |
| **Password** | Your **Consumer Secret** (from Settings → Integrations → API Keys) |

<Warning>
  Use your **Consumer Key** as the SMTP username and your **Consumer Secret** as the SMTP password, **not** your account email and login password. The Consumer Secret is generated in your dashboard under **Settings → Integrations → API Keys**. If you haven't created an API key yet, see [Create and Manage API Keys](/get-started/api-keys).
</Warning>

<Note>
  If your ISP blocks port 25 (the default SMTP port), use port **587** or **2525** instead. Port 587 with STARTTLS is the recommended choice for most environments.
</Note>

## Set up in popular email clients

<Tabs>
  <Tab title="Microsoft Outlook">
    These steps apply to Outlook for Microsoft 365, Outlook 2019, 2021, and Outlook Classic. The menu labels may vary slightly between versions.

    <Steps>
      <Step title="Open account settings">
        In Outlook, go to **File → Account Settings → Account Settings**. Select your email account and click **Change**.
      </Step>
      <Step title="Open More Settings">
        Click **More Settings** (bottom-right of the change account dialog), then select the **Outgoing Server** tab.
      </Step>
      <Step title="Enable SMTP authentication">
        Check **My outgoing server (SMTP) requires authentication**, select **Log on using**, and enter your Consumer Key and Consumer Secret. Keep these separate from your incoming-mail credentials.
      </Step>
      <Step title="Set the outgoing server">
        In your account's server settings, set the outgoing server to `pro.turbo-smtp.com` (or `pro.eu.turbo-smtp.com` for EU sending). Under **More Settings → Advanced**, set the outgoing port to `587` with **STARTTLS**, or `465` with **SSL/TLS**.
      </Step>
      <Step title="Save and test">
        Click **OK**, then **Next**, and use the built-in **Test Account Settings** button to verify that Outlook can authenticate and send a test message through turboSMTP.
      </Step>
    </Steps>
  </Tab>

  <Tab title="Mozilla Thunderbird">
    <Steps>
      <Step title="Open account settings">
        In Thunderbird, go to **Tools → Account Settings** (Windows/Linux) or **Thunderbird → Account Settings** (macOS).
      </Step>
      <Step title="Configure outgoing server">
        In the left panel, click **Outgoing Server (SMTP)**, then click **Add** to create a new server entry.
      </Step>
      <Step title="Enter SMTP details">
        Fill in the following values:
        - **Description**: turboSMTP (or any label you prefer)
        - **Server Name**: `pro.turbo-smtp.com`
        - **Port**: `587`
        - **Connection Security**: STARTTLS
        - **Authentication Method**: Normal password
        - **User Name**: your turboSMTP Consumer Key
      </Step>
      <Step title="Save and assign">
        Click **OK** to save. Back in Account Settings, select your email account, scroll to **Outgoing Server (SMTP)**, and choose the turboSMTP server you just created from the dropdown.
      </Step>
      <Step title="Send a test email">
        Compose a new message and send it. Thunderbird will prompt you for your SMTP password on first use : enter your **Consumer Secret**.
      </Step>
    </Steps>
  </Tab>

  <Tab title="Gmail / Google Workspace">
    Gmail's **Send mail as** feature can send through an external authenticated SMTP server. Availability depends on your account and Workspace policy.

    For organization-wide Google Workspace routing, use Google's outbound-gateway configuration and confirm its authentication requirements with your administrator. The Admin console's **SMTP relay service** configures Google's relay, not turboSMTP.

    **For personal Gmail (Send mail as):**

    Go to **Gmail Settings → Accounts and Import → Send mail as → Add another email address**. Enter your sender address, then on the SMTP configuration screen use `pro.turbo-smtp.com`, port `587`, your Consumer Key as the username, and your Consumer Secret as the password.
  </Tab>

  <Tab title="WordPress">
    WordPress does not support authenticated SMTP out of the box, so you'll need an SMTP plugin such as **WP Mail SMTP**, **Post SMTP**, or **FluentSMTP**.

    Install your preferred SMTP plugin, then enter the turboSMTP settings:
    - **SMTP Host**: `pro.turbo-smtp.com`
    - **SMTP Port**: `587`
    - **Encryption**: TLS
    - **Username**: your Consumer Key
    - **Password**: your Consumer Secret

    For full integration instructions for WordPress and other platforms, see the [Integrations](/integrations/overview) section of the documentation.
  </Tab>
</Tabs>

## Set up in your application

For applications that send email programmatically, configure your SMTP library using the same credentials. Here's an example configuration block you can adapt to your language or framework:

```yaml Configuration example
smtp:
  host: pro.turbo-smtp.com
  port: 587
  encryption: starttls
  auth: true
  username: "YOUR_CONSUMER_KEY"        # your Consumer Key from API Keys
  password: "YOUR_CONSUMER_SECRET"     # your Consumer Secret from API Keys
```

<Note>
  Use the [HTTP send API](/api-reference/send-email) if your application works more easily with HTTPS and JSON. SMTP also supports MIME attachments and custom headers.
</Note>

## Verify your connection

After configuring your SMTP settings, send a test message to confirm everything is working:

<Steps>
  <Step title="Log in to your dashboard">
    Go to [dashboard.serversmtp.com](https://dashboard.serversmtp.com) and log in.
  </Step>
  <Step title="Check the email log">
    Navigate to **Analytics**. Any email you've sent through turboSMTP will appear here with its delivery status (delivered, bounced, deferred, etc.).
  </Step>
  <Step title="Confirm delivery">
    If you see your test message listed with a **Delivered** status, the recipient's mail server accepted it. This does not guarantee inbox placement. If the message shows as bounced or deferred, check that your Consumer Key and Consumer Secret are entered correctly and that the port you selected is not blocked by your network or firewall.
  </Step>
</Steps>
